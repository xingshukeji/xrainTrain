# 能力与接口学习地图

Status: Proposed

核对日期：2026-10-25

资料快照：skills-hub `9a228f0`，核对时工作目录无修改

用途：为[独立培训课程设计方案](设计方案.md)确定能力覆盖、接口资料入口和初学者的学习深度。

本地图由独立工程 `xrainTrain` 维护，当前位于 `internal/`，用于课程实现前的覆盖审阅。相邻仓库链接供作者本地核验；发布给学习者的地图必须转换为可访问的课程或资料链接。工程与发布决定以[设计方案](设计方案.md)为准。

本地图以 skills-hub 当前的 [9 个技能入口](../../skills-hub/README.md)及[业务开发技能](../../skills-hub/skills/workforce-business-development/SKILL.md)的 21 份专题参考为资料范围，补充 Workforce 的公开消费契约。技能是资料来源，课程按学习者的问题重新组织。历史能力报告中的旧数量不作为当前清单。

这里核对的是资料与合同覆盖，没有重新调用全部接口，也没有验证运行目标的全部能力。所有相关接口资料应有查阅入口；“全部”指本地图登记的开发资料范围，不表示动态目录或 skill 已列出低代码平台的每条路由。制作课程时，新增的正式公开资料也须纳入对应位置。

## 1. 初学者学习到什么程度

| 深度 | 要求 | 课程中的位置 |
|---|---|---|
| 起步 | 照完整步骤做出第一个真实结果，解释字段与记录的区别 | Getting Started：一个自定义对象、一个文本字段、一条记录 |
| 基础必做 | 能查文档、使用常用能力、核对结果并处理一种相关错误 | B1—B7；不会这些就难以独立做小改动 |
| 入门认识，按需动手 | 知道能力解决什么问题、前置是什么、去哪里查；实际用到时做最小练习 | 能力地图与开发专题；不要求首课全部配置 |
| 维护者专题 | 在承担对应职责并具备权限时学习管理、迁移、恢复和交付 | 身份、授权、安装恢复和运行维护 |

学习深度不授予操作权限。认识 Token 不要求初学者签发 Token；认识安装恢复不要求每个人操作共享应用升级。第一轮使用已经准备好的目标与身份。

基础课必须让学习者掌握八件事：对象与字段、系统字段与记录值、查看有效元数据、查找和阅读接口、简单读写与查询、当前身份与权限层次、包及安装版本、错误与回读。日期/金额等类型一旦引入，就按真实传输合同解释，不能先教会丢失精度的写法再留待进阶纠正。

### 必要的 SVG 图与课程对应

以下是课程制作的图示要求，尚未绘制交付。每张图采用本课的最小例子，图源与课程共同维护；正文提供等价文字。正确性依据沿用上表的对应资料。

| 课程或问题 | SVG 应讲清什么 | 核对重点 |
|---|---|---|
| Getting Started：怎样得到第一条便签 | 定义 → 构建包 → 导入 → 安装 → 查看有效字段；随后保存并回读一条记录 | 安装模型与写入业务记录是不同动作，不能画成安装后自动出现这条便签 |
| B1：定义与数据有什么关系 | 对象、字段定义与一条记录值的对应关系 | 使用关系图表达包含和引用，不把静态关系画成执行步骤 |
| B2—B3：页面与接口怎样读写同一条记录 | 发起方、目标接口、输入、响应及回读；区分请求与返回箭头 | 路径、字段值、身份和 recordId 与本课例子一致；不虚构平台内部存储流程 |
| B5：为什么允许或拒绝 | 当前身份、租户、准入及对象/字段/记录条件与某次动作的关系 | 标明这是逻辑判断示意；分支有条件，不宣称内部检查一定按图中的顺序执行 |
| B6：改数据与改定义怎样生效 | 两条独立路径：记录修改后回读；定义变更经包和安装成为有效定义 | 已构建、已安装与当前有效定义不混为一种状态 |
| B7：失败后下一步查什么 | 从一个实际错误出发，展示下一项检查及可能结果 | 只展开本例相关分支；无权限、未找到、冲突与服务错误不合并为同一种失败 |
| Trigger、Routine 与外部集成专题 | 按专题分别展示提交前后、计划与实际执行、调用与外部结果 | 保留执行身份、异步和部分失败的含义；不暗示外部副作用会随本地事务自动回滚 |

图中的箭头必须能解释为动作、数据传递、依赖或状态转换之一，并通过标签或图例区分。普通表格已经表达清楚的内容不再重复绘图；需要多步理解的流程优先使用 SVG，避免仅用长段文字描述。

### 3.3 在线发现的实际入口与限制

以下是已提供合同中的发现入口，制作实操时还须核验目标版本、访问资格和响应：

```text
GET /api/metadata/v1/business-objects
GET /api/metadata/v1/entities/{entityCode}/describe
GET /api/metadata/v1/standards/entity-design
GET /api/data/v1/query-capabilities
GET /api/service/authen/v1/security/tenant-api-catalog?catalog=external
GET /api/orchestration/v1/callables
GET /api/integration/v1/http-interfaces/catalog
```

接口目录的 admission、requiredPermission、requiredRole 和 callableInCurrentSession 描述入口条件；记录权限与业务状态仍独立检查。目录读取失败与目录为空必须区别处理。

[2026-10-23 验证记录](../../skills-hub/skills/workforce-business-development/references/api-verification.md)指出，当时 `catalog=directory` 和 `catalog=external&format=openapi` 返回 500。该历史结果不证明当前仍失败，也不证明已修复。本轮未确认统一 Swagger/ReDoc 网站地址，课程不能虚构入口或把 OpenAPI 可用性当作既成事实。

API 中心的 api-debug 和编排 debug 会真实执行动作，包括写入或外部投递。基础接口练习先使用只读发现和明确的一条练习记录；调试按钮不能被讲成无副作用的模拟器。

## 4. “会看文档”必须有练习

第一道查阅练习使用 Getting Started 已保存的便签，任务是“通过公开接口读取这条记录”。课程提供目标与获准身份的取得方式，但让学习者自己从文档入口找到对应合同。

| 必须找到的内容 | 本例如何判断 |
|---|---|
| 接口属于哪个系统 | 查 XRain 数据接口，不把 Workforce 页面地址或 Runtime 地址当作同一个服务 |
| 方法与路径 | 找到单条记录读取，区分对象 describe；路径中的 entityCode 和 recordId 来自实际结果 |
| 身份与租户 | 使用该入口支持的既有认证方式；请求里的任意 userId/tenantId 不改变执行身份 |
| 输入与保存值 | 读取路径参数；后续修改时，业务字段值放在 values 中，不提交字段定义 |
| 成功响应 | 找到 recordId、values 及所需字段；保存值与页面显示标签分别解释 |
| 错误与下一步 | 结合状态、errorCode 和正文区分无权、未找到、冲突和服务错误，不统一当空数据 |
| 输出层次 | CLI 的 ok/data、HTTP 原始正文、SDK 解包结果分别按本层合同解释 |
| 生效与回读 | 修改后仍读同一 recordId；请求成功不自动证明其他页面、投递或后续任务完成 |

随后给一个未逐字演示过的筛选需求，让学习者找到查询合同、当前字段及允许运算符，并解释返回的分页与总数。以这项迁移练习判断是否会查资料，不考背诵路径。

每份接口练习提供一个成功例子和一个相关失败例子，保留实际返回结构。已知 404 空正文、204 空正文、JSON null、空数组和服务错误不能被统一改写成一种“无数据”状态。

## 6. 覆盖与发布前核验

课程维护者按“来源资料 → 能力 → 学习深度 → 页面/查阅入口 → 练习结果”审阅覆盖。21 份业务参考均在本地图有对应入口；其中验证依据用于判断证据边界，企业案例用于后续对照，不直接改成 21 堂必修课。

完整交付使用现有 GitHub 独立仓库 `xingshukeji/xrainTrain`，并通过 GitHub Actions 自动发布 GitHub Pages 课程网站，具体约定见[设计方案](设计方案.md)。发布前及上线后，核验以下影响教学的事实：

- 最小便签样例能真实构建、导入、安装、保存和回读；首课的菜单和命令均来自实际目标。
- 文档入口对目标学习者可访问；接口族、所属系统、使用对象和版本清楚，缺失资料有具体所有者。
- 从 GitHub 取得的干净课程副本可按 README 独立安装、检查、构建和预览；源码、SVG 图源、练习样例及锁文件齐全。
- `main` 推送触发的构建与 Pages 发布成功，在线网址对应实际发布提交；`/xrainTrain/` 基址下的课程、搜索、SVG、练习、样例下载和学习记录均可使用，深层页面可直接打开并刷新。
- 发布后的学习入口不含本机绝对路径或相邻仓库依赖；内部参考不会因课程仓库或网站公开而被意外发布。
- 当前目标的 JSON 目录、字段描述、设计标准和所需调用可用；OpenAPI 若尚不可用，提供已核验的替代查阅入口并说明范围。
- SDK、CLI、HTTP 与应用包例子分别匹配对应版本和数据形状；公共包导出与类型可找到。
- 首课不省略平台必需声明；不假设默认已有视图、所有页面自动消费元数据，或运行查询支持任意 SQL/groupBy。
- 扩展例子仅使用核验过的能力；课程不会因动态目录出现名称，就宣称文件、邮箱、通知、Trigger 或跨系统业务已完整可用。
- 基础课学习者能独立完成一次新查询、小改动与故障判断；网页模拟、本人操作和维护者复核分别记录。
- SVG 的节点、连线、分支和状态与所引用合同及本课实测一致；文字可读、缩放完整，交互可暂停并支持键盘，静态图和文字说明仍能解释结论。

平台缺少正式说明、查看入口或可定位错误时，归对应产品所有者补齐。培训项目维护学习路线和解释，不接管平台 API 规范、账号管理或业务实现。
