# 平台能力地图

先问“我要让谁完成什么动作”，再选能力。**基础课要求亲手使用常见接口；其他能力先知道用途、前置和资料入口，用到时再做最小练习。**

本地图覆盖本课程整理的 23 类能力，来源于当前开发资料范围。它不是平台全部 API 路由的清单，也不是 23 个必须依次完成的大项目。

## 基础必做

| 能力 | 先学会什么 | 从哪里开始 |
|---|---|---|
| 业务与平台分工 | 用实际动作选择模型、接口或已有系统；便签只需要存取文字 | [G0 第一条便签](/start) |
| 对象、字段与标准能力 | 区分定义、系统字段与记录值 | [B1 定义与记录](/basics/model) |
| 元数据、视图与呈现 | 读取有效 describe，理解显示与存储各自职责 | [B1](/basics/model)、[B4 字段](/basics/fields) |
| 记录读写与简单查询 | 保存、回读、修改、分页和一个筛选条件 | [B3 读写与查询](/basics/data) |
| 选项与关联 | 区分 label、稳定值、定义 ID 与目标记录 ID | [B4 字段](/basics/fields) |
| 身份、租户、准入与权限 | 读取自身 context，定位一个明确的拒绝原因 | [B5 身份与权限](/basics/access) |
| 应用包与安装版本 | 区分构建、导入、安装及业务数据变化 | [B6 修改定义](/basics/version) |
| 日期、时间与精确数值 | 使用所选字段类型的正确传输方式 | [B4 字段](/basics/fields)、[时间与执行人](/topics/automation#时间与执行人) |

## 承担维护职责时再深入

| 能力 | 需要先明确 | 入口 |
|---|---|---|
| 模型变更与安装恢复 | 确定版本、目标、修订、影响和原操作状态 | [安装维护](/topics/operations) |
| 身份生命周期与环境运维 | 实际人员与职责、既有身份、环境所有者及授权范围 | [环境准备](/help/environment)、[维护专题](/topics/operations) |

能力的学习深度不等于操作授权。认识一个 Token 接口不要求签发令牌，认识消息投递也不要求真的给别人发消息。动手时使用已准备的小例子和对应身份。

## 从问题选下一课

- “我要存一项信息” → 对象、字段、记录。
- “我要找出符合条件的数据” → 查询；不要先写自建搜索服务。
- “我要控制谁能操作哪一条” → 身份、对象/字段权限与记录范围。
- “我要在保存时校验或在某个时间执行” → Trigger 或 Routine，先确认时机与执行人。
- “数据已经在别的系统里” → 查原系统 API 与集成方式，再决定是否需要本地模型。
- “我要让 AI 参与” → 先定义具体业务动作、可用工具和授权，再验证执行结果。

每类能力的正式资料均在[资料总索引](/reference/sources)。需要具体方法、路径和返回时，进入[接口文档](/reference/)。
