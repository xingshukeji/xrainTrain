# 认识 XRain Workforce

XRain Workforce 是苏州苏宏助为智能科技有限公司提供的社交协作产品。人可以联系同事和具体的 AI 员工、聊天、分享资料、交办任务，也可以在工作台和业务应用中使用智能体。

## 从一件工作认识 Workforce

例如，一位店员正在接待顾客：她可以先查找顾客资料，在需要时向助手询问产品信息；遇到需要同事处理的事，可以在群里讨论，再明确创建任务交给负责人。需要定期检查的信息，可以按实际开放的能力设置定时安排。

这个例子中的几个动作各有自己的结果：**对话记录沟通，任务记录责任和进度，业务资料记录业务事实**。AI 的回答、任务状态和顾客资料的保存结果需要分别查看。

## 先记住这几个区别

| 容易混淆的事 | 怎样理解 |
|---|---|
| 消息与任务 | 聊天用于沟通；需要明确负责人和进度时使用任务。群里讨论、@ 一个人或 AI 回复都不会自动完成任务。 |
| AI 员工与智能体 | AI 员工是可以联系和交办的具体参与者；智能体定义描述工作要求、模型及能力，供获准的个人或应用使用。两者不是同一个概念。 |
| 应用中心与应用市场 | 应用中心帮助当前用户打开可用应用；市场用于查看上架应用包和可打开的应用，获授权的管理员还可以安装适用的包。 |
| 输入、运行与业务结果 | 消息发送、AI 运行、任务状态和业务数据保存分别确认。一个环节成功不代表其他环节也已经完成。 |

## 怎样判断自己能不能使用

登录后，先确认当前工作企业，再查看本人能进入的应用和数据。一个人可以属于多个企业；同一个账号在不同企业中的成员身份、应用权限和数据范围可能不同。

本组说明依据截至 **2026-10-30** 的 Workforce 产品需求和其中记录的实现差距整理，帮助理解功能方向。实际页面是否开放、哪些操作可用，要按企业部署的版本、设备、配置和本人权限确认。各页会单独指出已知差距与尚未核实的能力；示例用于解释，不代表某个环境已完成实测。

## 业务和开发从哪里接入

已有 ERP、CRM 等系统可以继续管理自己的数据，通过接口接入；新业务也可以使用 XRain 的对象、记录和权限能力。Workforce Application SDK 提供应用宿主、服务端和页面组件的公开入口；XRain Agent Runtime 负责智能体会话和工具执行。[了解已有系统接入](/developers/integration) · [了解 SDK](/developers/sdk) · [查看 AI 开发资料](/ai/)。
