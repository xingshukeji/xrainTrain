# XRain 业务应用平台

**XRain** 是苏州苏宏助为智能科技有限公司提供的业务应用平台。它支持建立新业务，也支持在保留原系统的情况下组织业务操作和提供接口。

## 已有系统继续发挥作用

如果 ERP、CRM 等系统已有清楚的数据、流程和权限，优先复用它们的接口。通过连接器管理目标配置和凭据，使用请求模板调用原接口；业务编排负责组合调用、转换参数或结果，再按需要发布统一业务接口。

这条路线**不需要先创建 XRain 业务对象或复制原系统的数据模型**。系统管理员仍需准备连接配置、接口权限和执行身份。只有出现原系统之外需要保存的新业务事实时，才考虑补充建模。

## 新业务按需要建设

| 能力 | 典型用途 |
|---|---|
| 对象、字段、关联与视图 | 建立业务台账、列表、详情和录入页面 |
| 记录、查询与数据授权 | 按人员职责读写、查询和统计业务记录 |
| 函数、业务编排与自动化 | 处理业务逻辑，响应记录事件，按时间执行动作 |
| 外部接口与公共服务 | 连接既有系统，使用文件、消息等已支持能力 |
| 应用包与安装维护 | 交付业务资源，检查版本、升级和恢复结果 |

## 与 Workforce 配合

XRain 提供业务数据和操作能力；[XRain Workforce](/products/workforce)提供人与 AI 协作和使用业务功能的入口。页面与 AI 工具可以调用同一业务操作，沿用对应系统的授权和结果。

开发时先选择[接入路线](/developers/)，再读取 [SDK](/developers/sdk)、[CLI](/reference/tools)或[官方技能](/developers/skills)。实际 API 以目标环境的接口目录和使用版本为准。

如需产品环境、接入评估或应用定制，请[联系我们](/contact)。
