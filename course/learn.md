# 人员学习

面向会编程、初次接触 XRain 的团队成员、企业开发者和合作伙伴。从一条便签开始，逐步理解模型、数据、接口、权限和应用版本。

**第一次学习，从 [G0：保存一条便签](/start) 开始。** 不需要先读完所有参考资料。

## 按当前目标选择

| 你的目标 | 直接进入 | 完成后应能做到 |
|---|---|---|
| 先看懂平台怎样使用 | [8 分钟操作视频](/platform-tour) | 认识记录、自定义权限、权限集与角色的操作位置 |
| 第一次亲手做成一个功能 | [基础课程 G0—B7](/start) | 保存数据、查字段和接口、修改与查询、配置权限、判断错误 |
| 已有基础，正在做具体需求 | [平台能力地图](/map) | 选择数据、自动化、集成或应用开发专题 |
| 正在调用接口 | [接口文档](/reference/) | 找到实际请求、身份要求和返回格式 |
| 正在扩展 Workforce | [字段到页面的综合练习](/topics/workforce) | 追踪平台字段、业务服务、接口和页面之间的映射 |
| 希望让 AI 协助开发 | [AI 开发资料](/ai/) | 把需求、参考资料和可用环境一起交给 AI |

## 最短学习顺序

**保存一条便签 → 理解对象和字段 → 调用接口 → 修改与查询 → 理解权限 → 升级与排错。**

基础课共 8 个单元。G0 使用浏览器，B1 开始使用 PowerShell 调用接口。网页模拟、自己操作平台和维护者已经验证的结果分别标识；阅读和答题不会代替平台实操。

真实操作需要[准备练习环境](/help/environment)。没有环境时，可以先看视频、阅读图解并答题。学习进度保存在当前浏览器，继续学习时打开[学习记录](/progress)。

## 课程之后

从[完整便签开发案例](/ai/note-case)理解一个资源包怎样从源码进入平台，怎样检查权限、读取记录和保留原数据升级。继续开发业务页面、服务或 AI 工具时，查阅公开的 [skills-hub](https://github.com/xingshukeji/skills-hub) 和[按开发任务组织的参考](/ai/reference)。

需要企业培训、业务方案或定制开发，查看[解决方案与合作](/solutions)。
