# 集成、文件与消息

当数据或动作已经属于另一个系统，先确认那个系统接受什么身份、提供什么接口。增加一个页面或 AI 工具，不会自动取得远端权限。

## 先分清三类 HTTP 资源

| 资源 | 便于理解的职责 | 一个最小例子 |
|---|---|---|
| Connector | 连哪个系统，使用哪份受管凭据 | 已配置的只读测试服务 |
| HttpRequest | 用什么方法、路径和输入模板请求 | GET 一个已知编号 |
| HttpInterface | 业务调用的稳定名称及执行资格 | “读取测试结果”入口 |

同一个 Connector 可供多个请求复用。HttpInterface 的 `raw` 类型关联请求，`orchestrated` 类型关联编排。先用 GET `/api/integration/v1/http-interfaces/catalog` 找到实际的 `invokeMethod`、`invokePath` 和 `permissionName`；目录的变量清单不等于完整参数类型。

直接调用的常见返回是 `{statusCode,isSuccess,headers,body}`。外层 HTTP 200 后还要检查内部状态和业务内容。编排调用 raw 接口时，成功 JSON 可能直接返回解析后的 body；两个入口的返回不能混用。

### 最小只读练习

请环境维护者提供一个已经配置、允许你执行的只读测试接口和一组无敏感信息的输入。先写出预期返回，再按目录的 method/path 调用。对照三项结果：接口返回是否成功、远端状态是否成功、实际值是否符合输入。若权限不足，保留该拒绝，回到当前接口的执行资格；不要临时更换管理员。

本专题没有替你创建 Connector 或调用任意外部系统。该练习需要目标自己的接口合同；基础便签练习不依赖它。

## 配置与调用身份

| 需要保存的内容 | 应放在哪里 | 不能据此推断什么 |
|---|---|---|
| 本人的显示偏好 | 用户设置 | 不是共享业务规则 |
| 连接器使用的秘密 | 平台受保护变量或既有凭据配置 | 变量列表不应返回秘密明文 |
| 服务主体的调用资格 | 对应 API Token 管理入口 | Token 不等于真实用户登录态 |
| 用户在 ERP 的访问权 | 原系统接受的授权或委托链路 | 自填 `userId` 或 XRain token 不构成 ERP 用户委托 |

页面和工具只提供业务参数。远端地址、认证方式与身份关联由可信宿主管理。模板中的 `system.actorId` 可以用于审计，但只有远端认可对应协议时才表示代理用户。

## 一次动作涉及两个系统

假设远端已经创建了报价，本地保存报价编号失败。重新执行整个动作可能创建第二张报价。应先保留远端编号和本地失败结果，查询原请求，再依据原系统的幂等或恢复合同继续。

外部 HTTP 不属于 XRain 记录事务。多来源列表也不能假定拥有统一分页、总数或跨库 join。先分别说明来源、时间、筛选与分页能力；确有需要再设计同步或索引。

## 文件与附件

文件服务保存内容并返回稳定 `fileId`；业务应用保存这份文件与记录、会话或消息的关系。**上传成功、关联成功和有权下载是三项结果。**

按需练习使用一份自写、无个人信息的小文本文件。通过已交付的应用附件入口上传，记录 fileId，关联到自己的练习记录，刷新后再次打开。若上传成功但页面没有附件，先查关联是否保存；若下载被拒绝，核对当前用户与关联资源的访问范围。

平台 `/api/service/files/v1/files` 使用其规定的服务主体及权限。普通学习者复用应用附件入口，不自行签发服务 Token。SDK 是否提供文件客户端以所用版本的公开导出为准，不能按名称猜内部类。

## 消息与投递结果

| 结果 | 可以报告什么 |
|---|---|
| 协作 Task 更新 | 任务责任或进度发生变化 |
| 会话消息保存 | 该会话中有一条消息 |
| 通道受理发送 | 通道接受了请求，仍需核对后续状态 |
| 通道确认送达 | 仅对该通道实际确认的接收结果成立 |

三者不会因记录保存或 AI 运行结束而自动同时发生。通知需要已配置的通道、账户、模板、接收人和执行资格。目录中出现 `delivery.email.sendByTemplate` 等 callable，也不能证明当前配置能发送。

发送结果未知时，用原业务事件的幂等键查询。更换幂等键重试可能造成重复消息。真实发送需明确接收人、内容与授权；本课程只做结果判读，不默认给任何人发信。

## 个人邮箱是另一种身份范围

个人邮箱入口 `/api/delivery/v1/email/me` 使用真实租户用户登录态。Host、agent 身份和 API Token 不能替代这条个人链路。

读取当前账号与文件夹后，搜索返回邮件的 `reference`，读取正文时原样回传。reference 中的账号、文件夹、uidValidity 和 uid 共同定位邮件；不要按主题或 Message-ID 猜回另一封邮件。

草稿保存成功表示邮箱中有草稿，不能报告为已发送。`email_reference_stale` 要求重新检索；草稿结果未知时先核对邮箱，不直接重复创建。
