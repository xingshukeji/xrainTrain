# 集成、文件与消息

假设报价数据在另一个系统里，你想在 XRain 页面查看报价。需要先取得那个系统的接口，再配置连接和调用方式。

本页先讲一次只读 HTTP 调用。文件、消息和个人邮箱是后面的概念速查，不安排上传或发送练习。

## 三类配置，分别解决什么问题

| 配置 | 解决的问题 | 报价例子 |
|---|---|---|
| Connector，连接器 | 连哪个系统、使用什么凭据 | 报价系统的地址和认证配置 |
| HttpRequest，请求 | 用什么方法、路径和参数 | 按报价编号发出 GET 请求 |
| HttpInterface，接口 | 业务程序通过什么名称调用 | “读取报价”接口 |

一个连接器可以供多个请求复用。`HttpInterface` 的 `raw` 类型关联请求，`orchestrated` 类型关联编排。

通过 `GET /api/integration/v1/http-interfaces/catalog` 查已配置接口的 `invokeMethod`、`invokePath` 和 `permissionName`。具体输入还要读该接口的说明。

## 最小只读练习

请环境维护者提供一个可用的只读测试接口，以及输入和预期结果。准备好后：

1. 在目录中找到它，确认调用方法、路径和权限。
2. 按接口说明提交输入。
3. 比较返回结果与预期。

直接调用的返回通常包含 `statusCode`、`isSuccess`、`headers` 和 `body`。例如下面两种情况，外层都可能是 HTTP 200：

| 外层 HTTP | 返回中的 statusCode | isSuccess | 怎样理解 |
|---|---|---|---|
| 200 | 200 | true | 调用成功，再检查 body 是否是所需结果 |
| 200 | 403 | false | XRain 返回了调用结果，但远端拒绝了请求 |

**外层 200 不等于业务成功。** 通过编排调用 raw 接口时，成功 JSON 可能直接返回解析后的 body，读取方式要与直接调用区分。

## 配置与调用身份

| 内容 | 放在哪里 |
|---|---|
| 用户自己的显示偏好 | 用户设置 |
| 连接器的密码或密钥 | 平台受保护变量或既有凭据配置 |
| 服务程序的调用权限 | 对应 API Token 配置 |
| 用户在报价系统中的权限 | 报价系统认可的登录、授权或委托机制 |

页面传入报价编号等业务参数。远端地址、凭据和用户关联由服务端配置处理；在参数中填写某人的 userId，并不会自动获得他在另一个系统的权限。

## 远端成功，本地失败怎么办

假设远端已经创建了报价 Q-001，本地保存报价编号时失败。如果重做整个流程，可能创建第二张报价。

应保留 Q-001 和原请求信息，先查询远端结果，再按该系统的重试或幂等规则继续。外部 HTTP 请求不属于 XRain 的记录事务，本地失败不会自动撤销远端结果。

同样，拼接两个系统的列表时，需要分别处理分页和总数，不能默认存在跨系统 SQL join。

## 文件与附件

这里先理解三个动作：

1. **上传文件**：文件服务保存内容，返回 `fileId`。
2. **关联业务记录**：应用保存“这份文件属于哪条记录”。
3. **下载文件**：检查当前用户是否有下载权限。

上传成功，只完成第 1 步。平台文件入口 `/api/service/files/v1/files` 使用规定的服务账号和权限；业务附件功能还需应用自己的关联处理。

本课程不安排文件实操。开发附件功能时查[公共服务资料](/reference/sources#专题资料)。

## 消息与投递结果

“任务已完成”“消息已保存”“邮件已送达”是不同结果：

| 看到什么 | 说明什么 |
|---|---|
| Task 状态更新 | 任务进度发生变化 |
| 会话消息保存 | 会话中新增了一条消息 |
| 通道返回 accepted | 发送请求已被接收，尚需查看后续状态 |
| 通道确认 delivered | 该通道确认送达 |

发送还需要可用通道、账号、模板、接收人和权限。发送结果未知时先查询原请求；更换幂等键重试可能重复发送。

本课只讲如何判断结果，不向真实收件人发送消息。

## 个人邮箱是另一种身份范围

个人邮箱接口 `/api/delivery/v1/email/me` 使用真实租户用户的登录会话，Host、agent 或 API Token 不能代替这个用户。

查询得到的邮件 `reference` 包含账号、文件夹、uidValidity 和 uid。后续读取应使用完整 reference，不能只凭邮件主题猜测。保存草稿与发送邮件也是两个动作。

本课程不安排接入邮箱或读取邮件。需要开发时，查[个人邮箱资料](/reference/sources#专题资料)。
