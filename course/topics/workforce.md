## 自己写一张影响表

假设需求是“把任务内容的界面提示改得更清楚”。先分开判断：

1. 记录值是否改变？只改提示通常不需要改历史记录。
2. 字段 label 是否被目标页面直接读取？这份 Task 页面有自己的“任务内容”文案，不能承诺改元数据标签就会自动改变它。
3. DTO 属性是否改变？保持 `description` 时不应顺带重命名所有调用者。
4. 哪个最小验证能证明结果？打开实际编辑框，保存自己的测试任务，重新读取同一 taskId。

本页核对来源与需求影响，不修改 Task 字段定义或应用代码。后面的页面检查使用本人新建的合成任务。需要修改产品行为时，再由对应项目确定目标、身份和预期结果。

## AI 参与一个已有业务动作

先把动作写成人能够判断结果的句子，例如“读取我有权查看的一条任务，返回内容和状态”。本练习使用应用提供的 Task 读取能力；业务开发者接入 AI 时，也应复用同一读取规则。

本练习的 Task 编号和执行身份由任务入口绑定。读取工具 `workforce_check_context` 的参数是空对象 `{}`，不让模型自行填写用户或 Task 编号。AI 输出的自然语言也不能替代服务返回的实际记录。

| 条件 | 说明 |
|---|---|
| 定义启用 | Runtime 允许该智能体执行，还需满足使用资格 |
| 个人订阅 | 使用个人路径时检查 selected 与 approvalStatus |
| 应用选用 | 应用路径按当前应用准入、绑定和启用状态判断 |
| 工具与数据权限 | 每次实际动作仍检查执行者的数据和业务资格 |

能选中助手，不等于能访问所有记录。工具执行结束，也不等于协作 Task 已经完成。Task 表示责任与进度，Session/Run 表示执行过程，业务记录保存业务事实。

## 判断一次只读工具是否成功

### 前置任务：准备 Task 执行入口 {#准备-task-执行入口}

先准备本人能够打开的一条合成 Task，内容只写课程练习要求，不包含客户、联系人或真实业务资料。**本人作为任务创建者或当前负责人，可以按 Task 读取规则查看该任务。** 不需要为此取得后台对象管理权限。

| 顺序 | 谁来做 | 完成后应看到什么 |
|---|---|---|
| 1. 确认原人物 | 学习者用自己的固定账号登录，打开合成 Task | Task 的内容和状态可见；记录同一 taskId |
| 2. 确认执行入口 | 维护者交付可用的任务智能体执行入口、模型和运行环境 | 从同一 Task 可以明确开始执行，仍使用本人身份，负责人不变 |
| 3. 核对已有读取能力 | 维护者核对 Task 执行入口是否已接入原业务读取服务 | 实际读取同一 Task 的内容和状态；不要求学员自建处理器、增加对象权限或发送消息 |
| 4. 按入口核对资格 | 若使用个人智能体路径，学习者在“我的智能体”选择已有获准助手；需要审批时由原管理者处理 | 个人路径的助手可用；Task 路径按本身的任务授权和模型合同使用，不把没有个人助手直接等同于没有 Task 读取权 |
| 5. 检查运行 | 学习者从自己任务的详情打开“智能体执行” | 使用本人身份创建执行，并能看到这一轮实际工具结果 |

本课使用 Task 详情中的执行入口，**不需要先订阅个人助手**。环境维护者应确认应用已包含 Task 读取接入修复，并提供可用模型；其他环境不能只凭相同版本号推断已经具备该修复。个人工作台的助手资格单独判断。

**应用能读、执行入口能读、AI 实际读取成功，是三项需要分别核对的结果。** 只有更新工具时不能把更新当作读取。若本人已能在页面查看，执行入口却未接入读取能力，应交由产品维护者修复，而不是给学员增加全体任务读取、管理员资格或要求自建绕行工具。

### 执行并核对同一条 Task

1. 在“任务”中选择“新建任务”，填写“课程合成任务：只读取本任务的内容与状态，不发送消息、不修改业务数据。”，负责人选择自己，再“确认交办”。已有自己的合成任务时直接复用。
2. 重新打开同一任务，确认内容、负责人及待处理状态，再选择“智能体执行”。任务要求会预填到输入框；模型使用当前入口已经可用的选项。
3. 将本轮输入改为下面的只读要求后发送，检查这一轮实际调用的是 `workforce_check_context`。
4. 将返回的 Task 编号、内容、状态与页面逐项比较，再刷新任务。任务应仍为待处理（`open`），原内容、负责人和结果均不变。

> 请只调用 workforce_check_context 读取当前绑定任务，返回任务内容和状态，然后结束。本轮不调用任何其他工具，不修改任务，不发送消息。

本次真实工具结果摘录如下，只保留与练习有关的字段：

```json
{
  "authorized": true,
  "task": {
    "description": "课程合成任务：只读取本任务的内容与状态，不发送消息、不修改业务数据。",
    "status": "open",
    "result": ""
  }
}
```

已核对原人物、原任务、对应调用和工具结果；该轮正常结束，未调用任务更新工具，前后任务快照一致。若工具说成功但没有相应返回，保持“尚未确认”；若被拒绝，沿[B5](/basics/access)检查资格，不改用管理员。适用构建及验证范围见[资料索引](/reference/sources#适用范围与真实验证)。

个人路径出现“暂无可用智能体”时检查第 4 步；Task 执行入口受阻时检查第 2—3 步及实际错误。普通 Task 页面回读只能证明本人可以查看，不能替代 AI 工具执行结果。

不回复、重复消息或接管后迟到写入属于运行与会话排查。先保留当前请求和实际运行标识，再使用[资料索引中的排障入口](/reference/sources#技能入口)，不要反复新建智能体或会话掩盖问题。
