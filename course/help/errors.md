# 按现象排错

先写下“我预期看到什么”和“实际返回什么”。记录方法、路径、目标、当前身份、状态码与错误码；分享材料前移除 Authorization、密码和业务数据。

## 从第一处偏差开始

| 现象 | 下一项检查 | 继续阅读 |
|---|---|---|
| 无账号、环境或练习权限 | 联系练习环境维护者取得已有身份、目标和准备状态 | [环境准备](/help/environment) |
| 401 / 登录过期 | 核对该入口要求的认证种类，重新走原登录流程 | [当前身份](/basics/access) |
| 403 / forbidden | 读取 context，再查该动作的准入、对象、字段和记录范围 | [权限判读](/basics/access) |
| 404 / 查不到对象 | 核对 entity API 名、租户和安装状态 | [定义](/basics/model) |
| 404 / 查不到记录 | 核对 recordId、目标、软删除及该接口的可见性规则 | [记录接口](/reference/http) |
| 400 / 输入无效 | 对照有效 describe 和请求结构检查类型、必填及长度 | [字段](/basics/fields) |
| 409 / 并发冲突 | 重新读取当前值与版本，判断是否仍应修改 | [修改与冲突](/basics/data) |
| 503 / runtime_metadata_not_ready | 保留错误与 traceId，由维护者检查该安装的运行可用性 | [元数据未就绪](#元数据未就绪) |
| 保存显示成功，重新打开却不是该值 | 核对回读的同一 recordId、租户、字段和请求结果 | [首课](/start) |
| 改了源码，平台没变化 | 分开查构建、导入、安装和有效定义 | [版本](/basics/version) |
| 平台字段已变，应用页面没变 | 查页面是否读取该元数据属性，还是使用自己的文案 | [消费者练习](/topics/workforce) |
| 安装或写入超时 | 先查询原操作或既有记录，不立即重放 | [维护](/topics/operations) |
| HTTP 200 但集成失败 | 检查内部 statusCode、isSuccess 与远端业务结果 | [集成](/topics/integration) |
| OpenAPI 或目录返回 500 | 保留目标与错误，使用静态合同继续定位；不要猜端点 | [接口入口](/reference/) |
| 邮件 reference 失效 | 重新搜索取得完整 reference，不拼接旧 uid | [个人邮箱](/topics/integration#个人邮箱是另一种身份范围) |

状态码帮助缩小范围，不能独自证明唯一原因。例如记录不存在与不可见的返回策略以该接口合同为准，不根据 404 直接删除或重建记录。

## 元数据未就绪

本次在专题对象修改个人视图后，describe 仍能返回，但记录请求得到 `503 / runtime_metadata_not_ready`；等待后仍未恢复。这是本次目标平台的运行问题，不能解释成记录为空或用户密码错误。

获授权维护者可对**已核对的同一 installationId** 调用 `POST /api/application/v1/installations/{installationId}/check`。该入口刷新该安装的运行可用性，并用当前身份只读检查对象；不重新安装、不重建记录，也不补齐用户权限。读取返回 items 中 BizObject 的 status/errorCode，随后再回读原记录。

本次检查恢复了专题对象读取，原记录和值保留。普通学习者缺少应用维护资格时，保留原错误交给维护者；若检查后仍失败，继续按平台问题处理。这个恢复结果不代表元数据刷新问题的根因已经修复。

## 三个容易误判的返回

**安装 Succeeded**：本次操作成功，还要核对当前租户的实际安装与有效定义。

**编排 isSuccess=true**：该次编排运行成功，仍要看 output 是否符合业务预期；是否适合 Trigger 是另外的合同。

**通知 accepted**：通道受理了发送，不等于收件人已经收到。

## 请 AI 帮忙时给出什么

提供脱敏后的最小请求、实际返回、目标版本和预期结果。要求先解释证据、指出缺失信息，再给出下一项只读检查。不要发送密码、Token 或整个配置目录。

如果建议要求扩大权限、换管理员、重建账号、重复安装或重发消息，先核实它解决的是否真是当前错误。学习者应能解释每项操作的影响，不能只因为 AI 给出了命令就执行。

## 课程自身的问题

浏览器记录只保存在当前站点、当前设备。换设备、清除站点数据或使用隐私模式后，记录可能不同；这不会改变真实平台上的便签。

页面无法保存学习记录时仍可阅读。刷新后交互演示恢复初始状态是预期行为；平台练习的结果请到真实目标回读。发现课程内容与实际合同冲突时，保留具体页名和脱敏差异，到[课程仓库](https://github.com/xingshukeji/xrainTrain)反馈。
