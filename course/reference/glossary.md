# 术语速查

| 术语 | 在本课程中指什么 | 容易混淆的地方 |
|---|---|---|
| 对象 / Entity | 一类业务信息的定义，例如便签 | 不等同于已经创建的一条数据 |
| 字段 / Field | 对象的一项信息及其类型、约束 | label 是显示名称，API 名用于调用 |
| 元数据 / Metadata | 描述对象、字段等规则的数据 | 具体便签文字是记录值 |
| describe | 当前身份可取得的有效对象描述 | 本地 source 不代表目标已采用它 |
| recordId | 一条业务记录的稳定标识 | 不是 objectId 或 fieldId |
| values | 记录中按字段 API 名组织的值 | HTTP 和 CLI 的外层结构可能不同 |
| Tenant / 租户 | 当前操作所属的业务隔离范围 | 登录身份相同也可能进入不同租户 |
| context | 当前身份与目标上下文 | 前端输入的 userId 不能替代它 |
| 准入 / Admission | 是否允许进入某应用 | 进入后仍需实际动作与数据权限 |
| Owner | 记录归属主体，参与相应范围规则 | 不等于该主体自动拥有一切管理权限 |
| 权限集 | 一组可授予的动作或资源资格 | 不能用它替代登录与租户关系 |
| 角色 | 可关联权限集、再分配给已有成员的一组职责 | 不是另一个登录账号；成员可能有多个角色 |
| 自定义 / 客制化权限 | 由业务定义并检查的具体资格，通常以 `custom.` 开头 | 只创建名称不会自动授予对象读写权限；[看页面操作](/platform-tour#自定义权限) |
| source.json | 本例的完整应用资源源码 | 不包含本例创建的业务记录 |
| .appkg | 服务端构建的应用包制品 | 构建成功不等于导入或安装成功 |
| packageId / versionId | 包的稳定身份 / 一个版本身份 | 修改版本内容不能覆盖旧不可变版本 |
| installationId | 一个目标租户中的安装 | 同一包可以有不同目标安装 |
| revision | 资源或安装的当前修订条件 | 提交前读取，处理并发变化 |
| requestId / operationId | 一次逻辑操作的标识 | 未知结果先查原操作，不随意更换 |
| 幂等 | 重复请求按合同避免重复副作用 | 仅使用同一个字符串不自动获得幂等 |
| Function / 编排 | 可调用的业务逻辑 / 组合动作 | 目录和返回随具体入口而异 |
| Trigger | 记录事件触发的执行 | 提交前校验与提交后行为不同 |
| Routine | 按计划执行的动作 | 时间、时区、启用和执行人都要明确 |
| Connector / HTTP 接口 | 远端连接配置 / 对业务暴露的调用入口 | 不能根据目录存在推断已经配置可用 |
| Task | 协作责任、目标和进度 | Session/Run 表示执行过程 |
| DTO | 应用传递给调用者的数据结构 | 可能把 description__c 映射成 description |
| SDK / CLI | 程序调用库 / 命令行工具 | 都要匹配具体版本及输出合同 |
| SVG | 可缩放的矢量图 | 课程图解释合同，不揭示未知平台内部实现 |
