# 术语速查

遇到不熟悉的词，在这里查含义和例子。代码中的英文名称保留原样，方便对照接口。

## 数据与字段

| 名称 | 含义 | 例子 |
|---|---|---|
| 对象 / Entity | 一类业务数据的定义，可类比数据库的表 | 便签对象 |
| 字段 / Field | 这类数据的一项信息，可类比列 | 内容字段 |
| 记录 / Record | 具体的一条数据，可类比行 | 你保存的“你好，XRain” |
| 元数据 / Metadata | 描述对象、字段和规则的配置 | 文本、必填、最长 200 字符 |
| label | 页面显示的名称 | 内容、便签内容 |
| API 名 | 程序引用对象或字段时使用的名称 | `content__c` |
| describe | 读取对象当前配置与访问权限的接口 | 查看字段类型和必填项 |
| recordId | 一条记录的编号 | G0 中自己便签的编号 |
| values | 按字段 API 名保存的值 | `{ "content__c": "你好，XRain" }` |
| Lookup | 指向另一条记录的关联字段 | 账目关联到某条分类记录 |

## 用户与权限

| 名称 | 含义 |
|---|---|
| 租户 / Tenant | 隔离一组组织的配置和数据的空间 |
| context | 当前登录用户、租户等信息 |
| 应用准入 / Admission | 是否允许进入某个应用；进入后仍要检查数据权限 |
| 权限 | 允许执行的具体操作，例如查看或新建便签 |
| 权限集 | 放在一起管理和分配的一组权限 |
| 角色 | 按职责关联权限集，再分配给用户 |
| 自定义权限 | 业务自己定义并检查的权限，通常以 `custom.` 开头；[页面中称“客制化权限”](/platform-tour#自定义权限) |
| Owner | 记录归属，参与数据访问控制；可能与负责人、创建人不同 |

## 应用包与版本

| 名称 | 含义 |
|---|---|
| source.json | 本课可编辑的应用资源配置文件 |
| .appkg | 根据源码构建的应用包，供平台导入和安装 |
| packageId | 一个应用包的编号，跨版本保持不变 |
| versionId | 一个具体版本的编号 |
| installationId | 一个租户中的安装编号 |
| revision | 当前修订号，提交修改时用于检查是否发生并发变化 |
| requestId / operationId | 一次操作的编号，用来查询同一次安装或恢复的进度 |
| 幂等 | 同一个操作重复提交时，按接口约定避免重复产生结果；不是所有接口都支持 |

## 自动化与开发工具

| 名称 | 含义 |
|---|---|
| Function / 函数 | 有输入和输出、可以重复调用的操作 |
| 业务编排 | 把多项操作组织成一个业务动作 |
| Trigger / 触发器 | 在记录创建、修改或删除时执行 |
| Routine / 定时任务 | 按指定时间和执行用户运行 |
| Connector / 连接器 | 外部系统的地址与认证配置 |
| Task | 协作任务，保存内容、负责人和进度 |
| Session / Run | 一次会话或运行过程 |
| DTO | 接口传递的数据结构，例如把 `description__c` 转成 `description` |
| SDK | 程序调用库，提供可用的方法和类型 |
| CLI | 命令行工具 |
| SVG | 可缩放的矢量图，本课用于流程图 |

需要具体操作，查[能力地图](/map)；需要请求参数，查[接口文档](/reference/)。
