# G0 · 我的第一条便签

用约 15 分钟，在 XRain 中保存一条 **“你好，XRain”**，再重新打开它。

开始前，维护者应已经提供测试平台地址、练习租户、你的账号和可用的“学习便签”视图。缺少其中一项，查看[环境准备](/help/environment#开始前你应拿到什么)。这一课不用安装开发工具。

想先熟悉页面，可以看[操作视频的第一章](/platform-tour)。

<FlowSteps />

## 1. 打开“学习便签”

登录测试平台，确认当前租户，选择 **数据视图 → 学习便签**。视图较多时，先搜索“学习便签”。

你应该看到列表和“新建记录”按钮。没有这个入口时，请维护者检查教学包和账号权限。

## 2. 填写并保存

点击 **新建记录**，在“内容”中填写 `你好，XRain`，再点击 **保存**。已经做过后续标签练习的环境中，这一项叫“便签内容”。

保存后，列表应出现这段文字。多人同时练习时，结合创建人和创建时间找到自己的那一行。如果暂时没看到，先刷新列表查找，避免重复点击保存。

## 3. 重新打开同一条

在这一行点击 **查看详情**，确认内容仍是 `你好，XRain`。

这一步是在检查保存结果：输入框里的草稿已经变成了下次还能打开的记录。

## 4. 记下记录编号 {#记录编号}

在详情中打开 **系统标识**，复制 `recordId`，与便签内容一起记到自己的笔记中。

`recordId` 是平台生成的记录编号。后续课程用它读取和修改这条便签，不用重新创建。

## 自己做一次

关闭详情，再独立完成一次查找和打开。确认：

1. 内容是 `你好，XRain`。
2. `recordId` 与刚才记下的相同。
3. 能说清：“内容”是填写项，“你好，XRain”是填入的文字，`recordId` 是这一条的编号。
