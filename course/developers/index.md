# 开发者文档

这是**苏州苏宏助为智能科技有限公司**提供的 XRain 与 XRain Workforce 开发资料。先选择你要完成的业务，再进入对应的入门、参考和示例。

## 选择你的第一步

| 你要做什么 | 从这里开始 | 你将得到什么 |
|---|---|---|
| 将管理完善的老系统接入 AI 或新页面 | [已有系统与业务编排](/developers/integration) | 不新增业务模型的接口转接路线 |
| 建立新的业务记录和流程 | [第一条便签](/start) | 一个对象、一个字段、一条可读写记录 |
| 在应用代码中调用平台 | [SDK 入门](/developers/sdk) | 取得和核对开发包、读取记录、接入工具 |
| 在终端操作平台 | [CLI 安装与调用](/reference/tools#cli-命令与安装) | 使用已有身份查询、管理数据和应用包 |
| 让开发型 AI 实现业务需求 | [AI 开发入口](/ai/)与[官方技能](/developers/skills) | 按任务获取资料、执行并核对结果 |

## 从一个例子开始

- [完整便签案例](/ai/note-case)：包含模型源码、创建和查询数据、版本升级与检查结果。
- [SDK 读取便签](/developers/sdk#读取一条已有便签)：在已取得 SDK 的 Node.js 项目运行，返回原记录。
- [免建模的编排示例](/developers/integration#用编排组合已有接口)：展示输入、外部调用和输出；接入真实 ERP 前替换其接口配置。

## 提供给 AI

将 [llms.txt](/llms.txt) 与业务目标一起提供给 AI。它连接产品说明、开发文档、纯文本和官方技能；[全文](/llms-full.txt)便于集中阅读本站内容。

公开文档帮助 AI 检索和理解用法，不保证任何模型厂商会收录到训练数据。真实操作仍需项目环境和授权。资料和示例中的版本范围见各页说明。

首次接入需要产品环境或 SDK 制品时，请[联系我们](/contact)。
