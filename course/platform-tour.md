# 跟着视频认识平台

第一次接触平台，先看第一章，再去 [G0 保存自己的便签](/start)。学习权限时，看第二至六章。

点击章节可跳到对应位置，再按播放。手机上可以横屏或全屏查看表单。

<CourseVideo />

便签操作需要已有学习视图和读写权限。权限管理部分由维护者操作，普通学员观看即可。

视频录制于 2026-10-25，使用测试数据。已剪去等待和一次误选后的纠正过程，遮盖账号与环境信息；演示创建的数据和配置已清理。下面的步骤便于暂停后对照。

## 认识页面与保存便签 {#便签操作}

1. 进入 **数据视图 → 学习便签**。
2. 点击 **新建记录**，填写“内容”或“便签内容”，保存。
3. 在自己的那一行点击 **查看详情**，确认文字仍在。
4. 点击 **编辑**，修改并保存，再看列表中的新文字。

结果：同一条记录的内容变了。后面调用接口需要的 recordId，在详情的“系统标识”中取得，见 [G0](/start#记录编号)。

## 创建自定义权限 {#自定义权限}

进入 **组织与权限 → 权限管理 → 客制化权限 → 新建权限**。“客制化权限”是界面中对自定义权限的称呼。

| 填写项 | 视频中的值 |
|---|---|
| 权限名称 | `xraintrain.video.read`，表单已带 `custom.` 前缀 |
| 显示名称 | 课程演示：查看学习成果 |
| 帮助文本 | 说明这是课程演示权限，尚未接入业务功能 |

保存后，完整名称是 `custom.xraintrain.video.read`。

**创建权限名称不会自动控制业务功能。** 业务代码还要检查这项权限。这个视频只演示配置关系，没有给角色增加便签读写权限。

## 创建权限集并开启权限

1. 打开 **权限集**，搜索 `custom.xraintrain.video`，已有同用途项时先查看。
2. 新建“客制化权限集”，名称填 `custom.xraintrain.video`，显示名称填“课程演示权限集”。这个表单需要填写完整前缀。
3. 保存后打开 **权限 → 客制化权限**。
4. 把“授权状态”改成 **未开启**，搜索刚才的完整权限名。
5. 开启该权限，再切回 **已开启**，确认它在列表中。

开启后，该行会从“未开启”列表消失，这是筛选结果变化，不是权限被删除。

## 创建角色并关联权限集

1. 打开 **角色管理 → 新建角色**，编码填 `custom.xraintrain.video`，名称填“课程演示角色”。
2. 保存并重新打开，在 **权限集**标签中点击 **添加权限集**。
3. 展开选择器，搜索“课程演示”，选中刚才的权限集。
4. 收起候选列表，核对选中项，再点击 **添加所选**。

现在的关系是：**角色 → 权限集 → 权限**。

## 关联已有成员并核对结果

在角色详情的 **关联用户**中点击 **添加关联用户**，搜索已经准备好的测试账号，核对后添加。

再打开角色的 **权限**：

- “客制化权限”应包含 `custom.xraintrain.video.read`。
- “对象权限”仍为空，因为刚才没有选择任何对象权限。

成员通过角色获得了这组权限。要验证某个业务动作是否真的受它控制，还需要业务代码接入，并分别检查有权和无权用户的操作结果。

## 解除关联与自己练习

在该成员行点击 **取消关联**，确认关联用户列表为空。该用户从其他角色或直接权限集获得的权限仍然保留。

暂停视频，回答：

1. 权限集有什么用？
2. 角色有了权限集，为什么还要添加用户？
3. 本例为什么不能让用户读写便签？

::: details 对照答案
权限集把多项权限放在一起管理。把用户关联到角色后，这个用户才能通过该角色获得权限。本例只添加了演示用的自定义权限，没有添加便签对象和字段权限。
:::
